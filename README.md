## Background

Draw is a game designed by four hooligans in the summer of 2023. Draw Core is
another implementation of **Draw**'s core logic. This time built in cpp, and
intended to be the beginning of **Draw**'s end.

## Install


```bash
mkdir build
cd build
cmake ..
cmake --build .
cmake --install .
```

### Build Options

```bash
-DBUILD_TESTS=ON
```
